# Module 01 — Practice

Complete these independently. Store one public class per `.java` file using the matching filename. Do not commit compiled `.class` files.

## How to submit your own work

For each exercise, include:
- A short problem statement or link to the exercise number.
- Your approach in plain language.
- The Java implementation.
- At least two test cases, including one edge case.
- A short note about what you learned.

Suggested filenames:
- `Exercise01_Profile.java`
- `Exercise02_PrimitiveTypes.java`
- `Exercise03_TypeCasting.java`
- `Exercise04_Calculator.java`

## Easy

1. Print your name, city and learning goal.
2. Declare one variable of each primitive type and print it.
3. Convert a `double` to an `int`; explain what happens to the fractional part.
4. Check whether a number is positive, negative or zero.
5. Check whether a year is a leap year.
6. Print numbers from 1 to 100.
7. Print the multiplication table of a number.

## Medium

8. Read two numbers and print sum, difference, product, quotient and remainder. Handle division by zero.
9. Find the sum of the first `n` natural numbers. Consider negative input and overflow.
10. Write methods that return the maximum of two and three integers.
11. Write an `isEven` method and test positive, negative and zero values.
12. Build a menu-driven calculator using methods and `switch`.
13. Create overloaded methods to calculate the area of a square, rectangle and circle.

## Challenging

14. Implement factorial iteratively and recursively. Compare the trade-offs.
15. Write a method that swaps two array elements. Explain why array mutation is visible to the caller.
16. Predict output involving pre-increment, post-increment and short-circuit evaluation.
17. Demonstrate integer overflow and show how to detect it.
18. Read invalid numeric input and handle it without crashing.

## Self-review checklist

- [ ] I attempted the problem before looking for a solution.
- [ ] My code compiles on JDK 21.
- [ ] I tested normal and boundary cases.
- [ ] I can explain every important line.
- [ ] I can discuss time and space complexity where relevant.
- [ ] I can solve a variation without copying.
