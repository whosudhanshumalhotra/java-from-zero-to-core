# Java 8 and Functional Features

**Java baseline:** 21  
**Status:** Roadmap — lessons are added and verified progressively.

## Purpose

Functional interfaces, lambdas, method references, streams, collectors, Optional and the date/time API.

## Learning outcomes

By the end of this module, you should be able to:
- Explain the module's central concepts in your own words.
- Select and use the relevant Java language features or APIs correctly.
- Trace important behaviour and recognise common failure modes.
- Write and test small programs using the concepts.
- Discuss practical trade-offs and answer follow-up interview questions.

## Topic roadmap

- [ ] Functional programming concepts in Java
- [ ] Functional interfaces and java.util.function
- [ ] Lambda syntax, scope and variable capture
- [ ] Method references
- [ ] Stream pipeline: source, intermediate and terminal operations
- [ ] Collectors, grouping and reduction
- [ ] Optional: intended use and common misuse
- [ ] java.time date and time API
- [ ] Parallel streams: trade-offs and caution

## Required lesson quality

Each substantial topic should include a clear explanation, motivation, syntax, internal working where relevant, runnable Java 21 examples, expected output, edge cases, debugging guidance, exercises, interview questions with model answers, and authoritative references.

## How to study

1. Check prerequisites before starting.
2. Read one concept at a time.
3. Predict example output before running code.
4. Modify examples and test edge cases.
5. Complete exercises without copying.
6. Explain the concept aloud and answer follow-up questions.
7. Mark a topic complete only when you can implement and explain it.
