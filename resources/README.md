## How to use references

- Use the **Java Language Specification** for language semantics and rules.
- Use the **API documentation** for class and method contracts.
- Use **Dev.java** for guided learning material.
- Use examples to build intuition, then verify subtle claims against the specification or API documentation.

When adding a reference to a lesson, link directly to the relevant official page where possible and state what the reader should consult it for.
